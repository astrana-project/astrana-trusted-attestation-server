# acme-logo.png

Sample organisation logo for the development manifest, which describes a fictional "Acme Bank".

Public domain, from <https://en.wikipedia.org/wiki/File:Acme_2026.webp>. Not copyrighted, so it carries no attribution
requirement.

250x63, converted from the source WebP. A manifest logo is downloaded by every consumer on every fetch, so it is kept
small rather than banner-sized. The original is 1080x270, which as a full-size PNG would be 67 KB and roughly 89 KB once
base64-encoded into the manifest. At this size it is under 7 KB, about 9 KB encoded.

The .NET and Java development configurations use it from here, `shared/test/acme-logo.png`.
